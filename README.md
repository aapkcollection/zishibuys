# ZishiBuys

ZishiBuys is an SEO-first household-products affiliate marketplace starter.

## Current foundation
- Responsive AliExpress-inspired marketplace layout with unique ZishiBuys colors
- 9 household categories
- Product cards with Amazon CTA
- Special/custom order WhatsApp CTA
- Basic metadata, robots and sitemap
- Mobile/tablet/laptop responsive design

## Important
The Amazon URLs in `data/products.ts` are placeholders. Replace them with approved Amazon affiliate/product URLs before publishing.

This is the frontend foundation. The production version should add a real database, secure admin authentication, approved product-data/API integration, dynamic product/category/article routes, server-side SEO, analytics, and a proper content-management workflow.
